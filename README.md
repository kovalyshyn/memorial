# Меморіал полеглим захисникам України

Статичний сайт для QR-коду на меморіалі: перелік військових частин → стрічка з фотографіями полеглих та біографічними нотатками. Адаптований під мобільні, працює безкоштовно на GitHub Pages.

**Стек:** [Eleventy](https://www.11ty.dev/) (генератор статичних сайтів) + [Decap CMS](https://decapcms.org/) (веб-форма для додавання записів). Увесь контент — звичайні markdown-файли в репозиторії, жодних баз даних і платних сервісів.

**Шрифт:** [UAF Memory](https://rentafont.com/fonts/uaf-memory) — офіційний меморіальний шрифт ЗСУ (дизайнер Дмитро Растворцев, ліцензія CC BY-ND 4.0, безкоштовний для комерційного й некомерційного використання). Сам UAF Sans ліцензійно доступний лише підрозділам ЗСУ, тому для назв та імен використано саме меморіальне накреслення родини — воно й створювалося для пам'ятників і меморіалів. Файли шрифту лежать у `src/fonts/` (самостійний хостинг).

## Запуск локально

Потрібен Node.js 20+.

```bash
npm install
npm run dev
```

- Сайт: http://localhost:8080/
- Адмінка (додавання частин і воїнів): http://localhost:8080/admin/

Адмінка в локальному режимі пише файли прямо на диск (через `decap-server`) — GitHub не потрібен.

## Додавання записів

Через адмінку `/admin/`:

- **Військові частини** — назва + порядок у списку (+ необов'язковий опис).
- **Полеглі воїни** — ПІБ, частина (вибір зі списку), позивний, звання, дати народження/загибелі, фотографія, біографічна нотатка.

Або руками: markdown-файли в `src/units/` та `src/fallen/`, фото — у `src/uploads/`. Зразкові записи позначені «(зразок)» — видаліть їх перед публікацією.

**Порада щодо фото:** перед завантаженням стискайте до ~1200 px по довшій стороні (JPEG) — сторінка швидше відкриватиметься з мобільного інтернету біля меморіалу.

## Публікація на GitHub Pages (безкоштовно)

1. Створіть репозиторій на GitHub і запуште код (`git init`, `git add -A`, `git commit`, `git push`).
2. У налаштуваннях репозиторію: **Settings → Pages → Source: GitHub Actions**.
3. Усе. Кожен push у `main` автоматично збирає і публікує сайт (workflow вже налаштований у `.github/workflows/deploy.yml`).

Сайт буде доступний за адресою `https://<логін>.github.io/<репозиторій>/`.

### Власний домен

1. **Settings → Pages → Custom domain** — вкажіть домен, у DNS додайте CNAME на `<логін>.github.io`.
2. У `.github/workflows/deploy.yml` замініть `PATH_PREFIX: /${{ github.event.repository.name }}/` на `PATH_PREFIX: /`.

### Редагування записів після публікації

Рекомендований шлях — **[Pages CMS](https://app.pagescms.org/)** (безкоштовно, конфіг `.pages.yml` уже в репозиторії):

1. Власник репозиторію заходить на app.pagescms.org через GitHub і дає доступ до репозиторію (встановлюється GitHub App).
2. У Pages CMS відкриває репозиторій → **Settings → Collaborators** → запрошує редактора **на email**. Редактору GitHub-акаунт не потрібен: він отримує лист, заходить і редагує частини/воїнів/фото через форми.
3. Кожне збереження — це commit у `main`, тож сайт автоматично перезбирається і публікується за 1–2 хвилини.

Альтернативи: локальна адмінка + `git push`, або Decap CMS онлайн (потребує OAuth-проксі — не варте мороки).

## QR-код

Коли буде відома адреса сайту:

```bash
pip install segno
python -c "import segno; segno.make('https://ВАША-АДРЕСА', error='h').save('qr.svg', scale=10)"
```

`error='h'` — максимальна корекція помилок: код читатиметься навіть із частково пошкодженої/забрудненої таблички. Для гравіювання беріть SVG.

## Структура

```
src/
  _data/site.json     — назва меморіалу, присвята (редагуйте тут)
  units/*.md          — військові частини
  fallen/*.md         — записи про полеглих
  uploads/            — фотографії
  admin/              — Decap CMS
  css/style.css       — стилі
.github/workflows/    — автодеплой на Pages
```
